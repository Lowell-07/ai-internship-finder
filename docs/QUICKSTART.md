# Quick Start

## 1. Install

```bash
cd frontend && npm install
cd ../backend && npm install
```

## 2. Run

Terminal 1:

```bash
cd backend
npm run dev
```

Terminal 2:

```bash
cd frontend
npm run dev
```

## 3. Open

- Frontend: `http://localhost:3000`
- Backend health: `http://localhost:8000/api/health`

## 4. Validate

```bash
python scripts/validate.py
```
